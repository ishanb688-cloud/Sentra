    Straight answers

    Questions people ask

    Does Sentra open the links I check?

    No. It reads the address itself, looking for lookalike domains, shorteners and tricks, and never visits it. That is why checking a dangerous link here is safe.

    Is the message I paste stored?

    Sentra does not save the text you check. The History screen keeps only the result, the type and the time, and only in your own browser. You can clear it any time.

    Can Sentra tell me a payment QR is safe?

    No, and it never claims to. It shows who the QR says it will pay, whether it sends or receives money, and any warning signs. Your UPI app shows the account's registered name, so compare the two before you pay.

    What can Sentra miss?

    A brand-new scam with no familiar warning signs can slip through, so treat Sentra as a second opinion and not a guarantee. When in doubt, contact the sender through an official number you already trust.

    How Sentra decides

    Scam checkers usually look at one thing. Scams use several at once, so Sentra connects them before it gives a verdict.

    1. 1Read

      Separate readers study the message, every link, any payment QR address, and the app file. Nothing is opened or run.

    2. 2Weigh

      Each warning sign gets a weight, based on how strongly it shows up and how reliable that sign usually is.

    3. 3Connect

      Scams follow scripts. When signs line up, such as posing as a bank, adding pressure, then asking for a code, confidence rises.

    4. 4Explain

      You get a risk level, the exact evidence, and how the scam would play out. Sentra never says something is safe.

    What kind of detection is this?

    Sentra is a rule-based, explainable detection engine. It does not use machine learning. That is a deliberate choice: every verdict can be traced to named warning signs, their weights and known scam scripts, so you can always see why. The trade-off is that a brand-new scam with no familiar warning signs can slip through.

    How the score is calculated

    1. Each warning sign scores strength × reliability.
    2. Signs in one category combine with diminishing returns, so repeats count less.
    3. Categories combine at 0.6 scale, so one kind of sign cannot reach the top alone.
    4. A completed scam script (for example impersonation, then pressure, then a request for a code) adds a bonus.
    5. An official-domain match lowers the score, but is capped so it can never hide a full script.
    6. Under 30 Low signals, under 65 Suspicious, under 85 High risk, otherwise Critical. The same input always gives the same score.

    Real or fraudulent UPI?

    Sentra checks whether the code sends money while the message says you will receive it, whether the payee name matches who the message claims to be, whether a business-sounding name sits on a personal phone-number ID, and whether the UPI handle is familiar. It cannot know the account holder's registered name. Only your UPI app shows that, so always compare it before paying.

    App files

    Sentra reads permissions (SMS plus screen overlay), SMS interception priority, accessibility and device-admin requests, hidden app or code files, debug certificates, and whether a bank-like app uses that bank's official package ID. It does not yet compare the publisher certificate with each brand's official certificate, because that needs a reference database. The app is never installed or run.

    What Sentra cannot do

    • It never says something is safe. The lowest level is "Low signals".
    • It is not machine learning, so it recognises known patterns and does not learn new scams by itself.
    • Its test results come from cases written by the team, not independent real-world data.
    • A name inside a payment QR is typed by whoever made it. Only your UPI app can show the account's registered name.
    • It reads patterns, so a brand-new scam can slip through. Treat it as a second opinion, not a guarantee.
